Some minor tweaks to the original mod
Changes:

"Max" value will take into account the # of boxes currently in the racks
    Example: Salt - "Max" set to 4. There is 2 boxes of salt on the rack. You click the refill button and...
      Old: 4 will be added to cart ("Max" limits # of boxes to put in cart.)
      New: 2 will be added to cart ("Max" applies to actual rack storage. If there is 4 or more already in the storage - none will be added.)

"Max" value can be set to the max # of boxes all assigned racks can take
    Example: You have 3 designated racks for chicken. Each can take 1 box.
      Old: You can only set "Max" to 1, because this is how many boxes a chicken rack can take
      New: You can set "Max" to 3, because this is how many boxes all your chicken racks can take
