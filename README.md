Some minor tweaks to the original mod  
Changes:

"Max" value will take into account the # of boxes currently in the racks

&nbsp;&nbsp;&nbsp;&nbsp;Example: Salt - "Max" set to 4. There is 2 boxes of salt on the rack. You click the refill button and...

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Old: 4 will be added to cart ("Max" limits # of boxes to put in cart.)  

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;New: 2 will be added to cart ("Max" applies to actual rack storage. If there is 4 or more already in the storage - none will be added.)

"Max" value can be set to the max # of boxes all assigned racks can take

&nbsp;&nbsp;&nbsp;&nbsp;Example: You have 3 designated racks for chicken. Each can take 1 box.

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Old: You can only set "Max" to 1, because this is how many boxes a chicken rack can take  

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;New: You can set "Max" to 3, because this is how many boxes all your chicken racks can take
